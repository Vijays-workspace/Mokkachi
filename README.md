# Mokkachi Maintenance Services

Professional industrial maintenance and engineering solutions website.

## 🚀 Features

- **Responsive Design** - Works on all devices (mobile to 8K TVs)
- **PWA Ready** - Installable as a mobile/desktop app
- **SEO Optimized** - Structured data, sitemap, meta tags
- **Accessible** - Skip links, ARIA labels, keyboard navigation
- **Modern UI** - Glassmorphism, animations, vibrant colors

## 📁 Project Structure

```
Mokkachi/
├── index.html          # Main HTML page
├── index.css           # Main styles
├── contact.css         # Contact section styles
├── main.js             # JavaScript functionality
├── manifest.json       # PWA manifest
├── service-worker.js   # Offline caching
├── robots.txt          # SEO crawler rules
├── sitemap.xml         # Search engine sitemap
├── favicon.png         # Browser favicon
└── assets/
    ├── images/         # Service images
    └── icons/          # App icons
```
